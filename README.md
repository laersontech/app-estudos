# 📚 Gerenciador de Estudos

App em Python pra organizar a rotina de estudos, registrar simulados/questões e tirar dúvidas direto com IA.

## 🚀 O que ele faz

- **Registro de Estudos:** Marca matéria, assunto, tempo estudado, questões e acertos.
- **Painel de Desempenho:** Puxa o histórico do banco pra calcular horas totais, taxa de acerto e resumo das sessões.
- **Tirar Dúvidas:** Aba com assistente usando a API do Gemini pra explicar os assuntos.
- **Banco de Dados:** Conexão com o Supabase pra não perder o histórico ao fechar a página.

## 🛠️ Tecnologias

- Python
- Streamlit
- Pandas
- Supabase
- Google Generative AI
